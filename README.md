# nuklear-cr

Nuklear bindings for Crystal SDL3 renderer and SDL3 OpenGL3

## Installation

1. Add the dependency to your `shard.yml`:

   ```yaml
   dependencies:
     nuklear:
       github: guidipolito/nuklear-cr
   ```

2. Run `shards install`
